隐私政策

最后更新于 2026 年 11 月 23 日

网站访问 移动端游戏 第三方服务 数据保留 你的选择与权利 联系我们

本政策说明 CoolFunGame 的 Dream Aquarium 官网及移动端游戏（应用标识 com.coolfun.ocean）如何处理信息。游戏中实际使用的功能取决于平台、版本和设备设置。

网站访问

官网提供游戏介绍和本政策。网站页面不设置 Cookie，不使用浏览器本地存储、访问分析脚本、广告或注册表单。GitHub Pages 提供托管服务，访问时 GitHub 会出于安全目的记录并保留访客 IP 地址。关于 GitHub 的处理方式，请查看 GitHub 隐私声明。

移动端游戏

本地设置和进度
游戏在设备上保存关卡进度、游戏物品和奖励记录，以及声音、震动和语言等偏好，用于继续游戏。Android 的游戏存档保存在本机。
iOS 云存档与排行榜
使用 Game Center 时，游戏可通过 Unity Authentication 识别玩家，并通过 Unity Cloud Save 备份关卡进度、库存和防止奖励重复发放所需的记录。排行榜会向 Apple Game Center 提交符合条件的关卡分数。其他玩家可能看到 Game Center 按你的公开设置显示的昵称和分数。
使用分析、诊断和安装归因
启用这些服务的移动端版本会通过 Firebase Analytics 记录关卡开始、结果、使用功能和购买等事件，通过 Firebase Crashlytics 收集崩溃及相关应用、设备诊断信息。Tenjin 使用安装或设备标识、应用启动、教程、关卡等事件及可用的推广来源信息衡量安装和推广效果。iOS 上游戏会按系统机制请求跟踪授权。在适用的 iOS 版本上，该授权也决定游戏是否将 Tenjin 返回的活动与素材归因字段转给 Firebase。
应用内购买
iOS 购买由 Apple 处理。游戏使用交易标识和收据信息确认订单、发放商品和防止重复发放。签名收据及交易、商品、币种、单价和数量信息会发送给 Tenjin，用于购买归因。Firebase Analytics 也可记录已完成的 Apple 交易。
问题反馈与版本服务
使用游戏内反馈时，Unity Authentication 为请求提供玩家标识。游戏使用 Unity Cloud Code 和 Cloud Save 传送和保存你填写的反馈，以及请求标识、提交时间、平台、应用版本等信息，用于记录问题和限制重复提交。iOS 版本检查也会使用 Unity 匿名登录，以获取适用的版本更新信息。填写反馈时请避免提供密码、支付卡号或其他敏感信息。

第三方服务

我们使用以下服务提供相应功能。服务提供商可能按其隐私说明及所在地适用要求处理数据，包括在你所在国家或地区以外处理数据。

  • Unity 提供认证、云存档、反馈和版本服务。
  • Google Firebase 提供使用分析和崩溃诊断。
  • Tenjin 提供安装和购买归因。
  • Apple 提供 Game Center、应用商店及购买服务。
  • GitHub 提供官网托管和公开项目交流渠道。

数据保留

本地存档随设备上的应用数据保留。云存档在同步、恢复和处理存档冲突所需期间保留，旧文件可随同步清理。用于反馈、诊断、交易和归因的信息按处理问题、运行服务、核对交易及满足适用要求所需的期限保留。服务提供商的保留规则见各自的隐私说明。

你的选择与权利

  • 你可以在 iOS 的「设置 → 隐私与安全性 → 跟踪」管理应用跟踪授权，在 Game Center 设置中管理登录和资料可见性。
  • 你可以通过设备的应用管理功能清除本地数据。清除本地数据或卸载应用可能使本地进度丢失，已有的云端备份或服务商记录需要另行处理。
  • 根据适用法律，你可以请求访问、更正、删除或获取个人数据，限制或反对某些处理，或撤回基于同意的授权。请通过下方渠道提交请求。为保护你的账户，我们可能需要核实请求者身份。
  • 如果监护人认为孩子提供了个人信息，可通过下方渠道请求核查或删除。

联系我们

如需提出个人数据请求或反馈隐私问题，请使用游戏设置中的「客服反馈」入口，并注明「隐私请求」。如暂时无法进入游戏，可在 GitHub 项目问题区询问联络方式。问题区公开，请勿在那里填写账号标识、收据或其他个人信息。

政策更新时，我们会在本页发布新版本并更新顶部日期。
