# Dream Aquarium 官网

游戏主页和隐私政策由 GitHub Pages 托管。源文件是静态 HTML 和 CSS。

- [游戏主页](https://coolfungame.github.io/Home/)
- [隐私政策](https://coolfungame.github.io/Home/privacy.html)

在仓库根目录执行 `python -m http.server 8000` 后，可通过 `http://localhost:8000/` 预览。GitHub Pages 的发布源为 `main` 分支的根目录。更新隐私政策时，请核对上线版本、第三方 SDK 和反馈渠道，并同步更新页面日期。
